# Probier
Data and code used in the analyses reported in the manuscript entitled "(Mis)understanding intentions through pitch contours"

Authors: Pauline Larrouy-Maestri, Hanna Ringer, David Poeppel, & Daniela Sammler

# Content

- Probier_data.xlsx: Data for experiments 1 and 2
- df_LCA_reviewer_criticism.csv: Data for Exp. 2 (shortcut to avoid running the latent class analysis again).
- df_LCA_reviewer_suggestion.csv: Data for Exp. 2 (shortcut to avoid running the latent class analysis again).
- Probier_Contours.Rmd: Code for Exp. 1
- Probier_Contour.nb.html: Output for Exp. 1
- Probier_Online.Rmd: Code for Exp. 2
- Probier_Online.nb.html: Output for Exp. 2
